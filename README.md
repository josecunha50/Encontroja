# EncontroJá — MVP gratuito

Aplicativo inicial de encontros casuais, feito com Expo/React Native.

## O que já funciona nesta versão
- Tela inicial
- Cadastro local de nome, idade e intenção
- Descoberta de perfis de demonstração
- Curtir / passar
- Match
- Lista de Matches
- Tela de conversa (demonstração)
- Interface vertical para celular

## Como testar sem pagar

1. Instale Node.js no computador.
2. Abra esta pasta no terminal.
3. Execute:
   `npm install`
4. Depois:
   `npx expo start`
5. Instale o aplicativo Expo Go no celular e escaneie o QR Code.

## Próxima etapa

Esta é uma versão MVP/demo. Para transformar em um aplicativo real, a próxima etapa é conectar:
- Firebase Authentication
- Firestore
- Firebase Storage
- mensagens em tempo real
- perfis reais
- localização aproximada
- bloqueio/denúncia
- moderação
- painel administrativo

Importante: o aplicativo deve ser destinado a maiores de 18 anos e precisa ter regras de comunidade, privacidade e mecanismos de denúncia/bloqueio antes de receber usuários reais.
